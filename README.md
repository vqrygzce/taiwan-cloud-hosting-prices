## 先弄清楚：雲端主機、VPS、虛擬主機差在哪

三個詞對應三種資源分配方式。虛擬主機是把一台伺服器的空間分給大量用戶共享，便宜、免維護，但資源與風險也共享；VPS（也就是一般說的雲端主機）用虛擬化技術切出獨立的 CPU、記憶體與儲存空間，可以自己裝作業系統、跑資料庫，資源隨時線上升降；獨立伺服器則是整台實體機歸你用。

判斷方式很簡單：純網站、流量不大，虛擬主機最省錢；要跑系統、ERP、遊戲服、機器人這類長期在線的東西，直接看 VPS。雲端架構的另一層價值在備援——伺服器集群偵測到異常時會自動切換節點，這是單台實體機給不了的，多數業者對此提供 99.9% 等級的可用性承諾。

**第二件：頻寬的算法有三種流派。** 固定專線頻寬（陣列全系列內含 15Mbps，不因流量加收費）、流量配額（CheapServer 從 1TB 起，用完再看加購）、按用量計費（國際雲的主流，輸出流量是帳單裡最容易被低估的一項）。直播、下載站要盯頻寬上限，一般網站看流量配額就夠。三種算法下的「同價格」方案，實際成本可能差好幾倍。

**第三件：備份的「單獨」二字。** 好室網特別點出一個行業慣例：多數主機商只定期備份整台伺服器，你的站毀了，卻無法還原到你要的時間點，要求單獨備份往往得另外付費。他們的做法是每天對每個站點單獨備份、保留 30 天、免費。買之前務必問清三個問題：備份是整機還是單站？保留幾天？還原收不收費？
